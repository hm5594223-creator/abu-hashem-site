# منصة أبو هاشم للأمن السيبراني

موقع عربي RTL بتصميم أسود وأحمر، يحتوي على:
- واجهة متجاوبة للموبايل والكمبيوتر.
- صندوق أدوات: دليل فحص الروابط، مولد كلمات مرور محلي، مصادر معلومات الدومين، شرح رؤوس الحماية، SHA-256 محلي، ورمز QR.
- مساعد دردشة عبر API من خلال الخادم، حتى لا ينكشف مفتاح API في المتصفح.
- محتوى توعوي وروابط تعليمية.

## تشغيل محلياً
يتطلب Node.js 18 أو أحدث.

1. فك ضغط المشروع.
2. انسخ `.env.example` إلى ملف باسم `.env`.
3. أضف مفتاح API في `AI_API_KEY`، وحدد `AI_API_URL` و`AI_MODEL` حسب مزود الخدمة.
4. افتح الطرفية داخل مجلد المشروع وشغّل:
   ```bash
   npm install
   npm start
   ```
5. افتح `http://localhost:3000`.

إذا لم تضف مفتاح API، يبقى الموقع والأدوات متاحة لكن المساعد سيعرض رسالة توضح أن الخدمة غير مفعّلة.

## النشر المجاني من أندرويد باستخدام GitHub وRender
قد تتغير حدود الخطة المجانية لدى مزودي الاستضافة بمرور الوقت، وقد تحتاج حساباً للتحقق.

1. نزّل تطبيق GitHub أو افتح github.com من متصفح أندرويد وأنشئ مستودعاً جديداً.
2. ارفع ملفات المشروع: `package.json` و`server.js` و`.env.example` ومجلد `public` و`README.md`. لا ترفع ملف `.env` أو أي مفتاح سري.
3. افتح Render من المتصفح وسجّل الدخول.
4. أنشئ Web Service واربطه بمستودع GitHub.
5. الإعدادات:
   - Build Command: `npm install`
   - Start Command: `npm start`
6. من Environment Variables أضف:
   - `AI_API_KEY` = مفتاحك السري من مزود الذكاء الاصطناعي
   - `AI_API_URL` = عنوان API المتوافق مع واجهة Chat Completions
   - `AI_MODEL` = اسم النموذج المتاح لحسابك
7. انشر الخدمة وانتظر انتهاء البناء، ثم افتح رابط الموقع الذي توفره الاستضافة.

## ملاحظات مهمة
- الاستضافة المجانية لا تعني أن استخدام الذكاء الاصطناعي مجاني. مزود الـ API قد يطلب رصيداً أو وسيلة دفع، حسب خطته.
- لا تشارك مفتاح API ولا تضعه في `public/app.js` أو `public/index.html`.
- إذا استخدمت مزوداً لا يدعم واجهة Chat Completions المتوافقة، قد تحتاج إلى تعديل جزء الاتصال في `server.js`.
- أداة النطاق تفتح خدمات خارجية؛ لا تدّعي أن الموقع فحص النطاق بنفسه.
- مولّد كلمات المرور والتجزئة يعملان محلياً في المتصفح.
- أدوات الأمن مخصصة للتوعية والدفاع والأنظمة التي تملكها أو لديك إذن لاختبارها.
- قبل استخدام الموقع بشكل عام، أضف سياسة خصوصية وحدود طلبات ومراقبة إساءة الاستخدام، ولا تجمع بيانات حساسة بلا حاجة.
